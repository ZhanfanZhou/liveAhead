# 鲜知 XianZhi Frontend Demo

一个纯前端 React 演示应用，用深夜雷达式界面展示「爆品先知」如何在商品火之前预测、解释并盯品。

> ⚠️ 这是**用于方案评审的交互 Demo**：没有任何后端，所有商品、预测分、对话、盯品任务、命中率均为 `src/data/mockData.ts` 中的模拟数据，目的是让决策者直观感受产品形态与关键交互。

## Run

```bash
npm install
npm run dev
npm run build
```

## Screens

- `雷达`：个性化推荐流，热卖卡为金色实线，预测卡为电青虚线，并支持展开三路归因与历史 sparkline。
- `盯品`：对话脚本逐条播放，将自然语言编译成结构化盯品任务卡。
- `任务`：持久盯品订阅列表，支持三档授权切换与自动档风控展示。
- `复盘`：命中率、平均提前量、验证案例与三路信号贡献看板。

四屏可通过 URL hash 直达：`#radar` · `#watch` · `#tasks` · `#review`。窄屏（手机）自动切换为全屏移动布局。
